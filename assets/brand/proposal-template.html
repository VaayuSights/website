Thermal analysis — 12 MW rooftop array

Prepared for [ Client Name ] · [ Contact, Role ]

What you asked for

You have a 12 MW rooftop array near Chakan and a thermal survey flown in October that has not been analysed. You want to know which modules are underperforming before the maintenance window in January.

What we will do

  1. Ingest and quality-check the supplied survey, and confirm the capture supports module-level analysis
  2. Radiometric analysis across all frames
  3. Defect detection and classification by severity — hotspots, bypass diode failures, string faults
  4. Engineer review of every finding before it reaches you
  5. Module-level defect map keyed to your plant layout
  6. Report and a walkthrough call with your engineering team

What you receive

  • Module-level defect map, keyed to layout
  • Ranked defect list — location, type, severity, recommended action
  • Annotated thermal frames for every flagged module
  • Summary report, PDF
  • Processed outputs — orthomosaic GeoTIFF
  • One walkthrough call

What we need from you

  • The October survey imagery, with flight logs if available
  • Plant layout or string diagram
  • A named technical contact for questions during analysis
